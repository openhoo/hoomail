# Working on Hoomail

Hoomail is the development mail catcher in this repository. Read
`CONTRIBUTING.md` for change and pull-request conventions.

## Agent skills

- For development of Hoomail itself, read
  [hoomail-development](skills/hoomail-development/SKILL.md).
- For capturing and verifying another application's mail, read
  [hoomail-testing](skills/hoomail-testing/SKILL.md).

The development skill is also exposed through `.agents/skills`. Installable
skill sources live in `skills/`; keep the development discovery link relative.
Keep skill instructions aligned with source, package scripts, and CI when
changing the contracts they describe.
